# Project template editing

Template editing is split into task rows, prerequisite selection, and milestone rows. Removing a task also removes links to it and shifts later prerequisite indexes, keeping the remaining dependency references stable.

The exported file contains a copy of the template data at export time. It can be imported into another AVEN workspace that has permission to create templates. Importing creates a new workspace-owned template; it does not overwrite an existing template with the same name.
