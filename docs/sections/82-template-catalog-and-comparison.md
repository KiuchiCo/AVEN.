# Template catalog and comparison

The template creator now has a searchable, categorized starter-plan catalog. Starter content is loaded only when the creator opens, keeping its long task guidance out of the initial Projects page bundle. Each starter can be inspected before it is copied into the editor, and all fields remain editable before saving.

The catalog contains plans for product work, research, marketing, operations, education, career, personal routines, finance, health, and community projects. A starter plan includes task descriptions, priorities, labels, prerequisite links, relative task dates, and checkpoints. Saving copies the data into a workspace template; later edits do not mutate the starter catalog.

Users can star templates for the current workspace in the browser and show favorites only. Favorites are stored locally and are removed from the local list when a template disappears from the workspace. They are not shared with other members.

Comparison supports up to three templates at once. The comparison view lines up tasks and milestones by their current order and highlights differing task names. It also summarizes task counts, dependency links, scheduled items, distinct labels, schedule span, and usage. Comparison is a decision aid; it does not merge, alter, or apply any selected template.
