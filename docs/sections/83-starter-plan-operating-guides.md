# Starter plan operating guides

The extended preset catalog now gives each starter plan an operating guide in addition to its task list and relative schedule. The guide is available in the preset preview before the user loads a plan into the editor.

Each guide covers four areas:

- Preparation: purpose, approval ownership, capacity, decision rights, baseline, and source-of-truth ownership.
- Quality checks: evidence, affected participants, applicable policy and accessibility checks, and traceable acceptance criteria.
- Risk signals: scope movement, unavailable owners, late dependencies, weak evidence, high-impact failure, and recovery options.
- Handoff: final output, context, access, open questions, follow-up timing, and the progress location.

Guides are tailored to the individual plan and reference its tasks and audience context. They help a team inspect the workflow before using it; the editable task descriptions and checklist remain the content that is carried into a saved project template.
